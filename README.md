# Developer Portfolio

A modern, responsive developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Tech Stack

- **React 18** - UI library
- **Vite 5** - Build tool and dev server
- **Tailwind CSS 3** - Utility-first styling
- **Framer Motion** - Animations and transitions
- **Lucide React** - Icon library

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
Portfolio/
+-- public/assets/        Static assets (favicon, og-image, etc.)
+-- src/
    +-- assets/           Component-level assets
    +-- components/       Reusable UI components (Navbar, Footer, etc.)
    +-- sections/         Page sections (Hero, About, Projects, Skills, Contact)
    +-- data/             Static content data
    +-- hooks/            Custom React hooks
    +-- layouts/          Layout wrappers
    +-- App.jsx
    +-- main.jsx
    +-- index.css
```
